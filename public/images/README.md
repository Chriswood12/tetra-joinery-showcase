# Exhibition Photography Slots

Drop your own workshop and finished piece photographs into this folder, then uncomment the corresponding `src` line in `src/data/project.js`.

| Slot | Recommended Filename | Aspect Ratio | Description |
| :--- | :--- | :--- | :--- |
| **Plate 01 (Hero)** | `tetra-hero.jpg` | `16:9` | Wide shot of the Tetra table (extended or angled hero view) |
| **Plate 02 (Closed)** | `tetra-closed.jpg` | `4:3` | Compact closed cube highlighting the checkered grating top |
| **Plate 03 (Tray Detail)** | `tetra-tray.jpg` | `4:3` | Close-up of a reversible tray and corner joinery |
| **Plate 04 (Workshop)** | `tetra-craft.jpg` | `4:3` | Bench / workshop build shot (half-lap battens, tools, or oiling) |

*(WebP, JPG, or PNG files are all supported.)*
